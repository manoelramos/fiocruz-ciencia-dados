Tópico 6

Armazenando informações

No tópico anterior, você viu como escrever programas que exibiam mensagens e realizavam cálculos simples. Entretanto, até esse momento, todos os valores precisavam ser digitados diretamente no código, o que seria pouco eficiente em programas maiores, como um que calcula indicadores de mortalidade para diferentes municípios.

Para resolver esse problema, utilizamos variáveis: elas permitem armazenar informações para que possam ser reutilizadas ao longo do programa sempre que necessário.

O que é uma variável?

Uma variável é um espaço reservado na memória do computador utilizado para armazenar um valor. Uma forma simples de compreender esse conceito é imaginar uma caixa identificada por uma etiqueta: a etiqueta corresponde ao nome da variável, e o conteúdo da caixa representa a informação armazenada.

idade = 72
print(idade)

Resultado esperado:

72

Na programação, o símbolo = não significa igualdade matemática. Ele indica que um valor está sendo atribuído a uma variável.

Por que utilizar variáveis?

O uso de variáveis torna os programas mais organizados e fáceis de modificar. Compare:

# Sem variável — seria preciso alterar cada linha manualmente
print("Idade: 72 anos")

# Com variável — basta alterar o valor uma única vez
idade = 72
print("Idade em anos:", idade)

Se o valor armazenado na variável for alterado, todas as mensagens que a utilizam são atualizadas automaticamente, o que reduz a possibilidade de erros e facilita a manutenção dos programas.

Escolhendo bons nomes para variáveis

Programas bem escritos utilizam nomes que descrevem claramente a informação armazenada.

# Pouco recomendável
a = 72
b = "F"

# Mais recomendado
idade = 72
sexo = "F"

Mesmo sem conhecer Python, é possível compreender rapidamente o significado das informações armazenadas, o que facilita tanto o desenvolvimento quanto a revisão do código.

Dica

Ao criar uma variável: o nome pode conter letras e números, não pode iniciar com número, pode usar _ (underscore) e diferencia maiúsculas de minúsculas. Prefira nomes completos como idade, municipio e total_obitos em vez de abreviações pouco intuitivas.

Tipos de dados

Nem todas as informações possuem a mesma natureza: uma idade é diferente de um nome de município, que é diferente de um código da Classificação Internacional de Doenças (CID). Por isso, Python organiza as informações em diferentes tipos de dados.

Principais tipos de dados no Python

TipoUtilizaçãoExemplo
intNúmeros inteiros72
floatNúmeros com casas decimais14.8
strTextos"Lavras"
boolValores lógicosTrue ou False

Você pode verificar o tipo armazenado utilizando a função type().

idade = 72
taxa_mortalidade = 14.7
municipio = "Lavras"

print(type(idade))
print(type(taxa_mortalidade))
print(type(municipio))

Resultado esperado:

<class 'int'>
<class 'float'>
<class 'str'>

Em Python, os números decimais utilizam ponto como separador decimal (14.7, em vez de 14,7). Valores do tipo bool (booleanos) podem assumir True (verdadeiro) ou False (falso) e aparecem com frequência como resultado de comparações e em estruturas condicionais.

Construindo mensagens com f-strings

Uma forma prática de combinar textos e variáveis é utilizar f-strings. O f antes das aspas indica ao Python que o texto contém expressões que devem ser substituídas pelos respectivos valores.

municipio = "Uberlândia"
obitos = 528

print(f"No município de {municipio} foram registrados {obitos} óbitos.")

Resultado esperado:

No município de Uberlândia foram registrados 528 óbitos.

As expressões colocadas entre chaves ({}) são substituídas automaticamente pelos valores armazenados nas variáveis. As f-strings tornam o código mais legível e direto.
