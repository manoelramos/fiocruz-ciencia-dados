Introdução à Análise de Dados com Pandas

Tópico 8

Limpeza e tratamento de inconsistências

Bancos administrativos reais frequentemente contêm campos não preenchidos, colunas com o tipo de dado incorreto (números lidos como texto) e nomes de campos pouco claros. O tratamento prévio garante que as análises subsequentes sejam precisas.

Identificação de valores ausentes

O método isnull() verifica cada célula do DataFrame e identifica se ela contém um valor ausente. O resultado é uma estrutura (vetor) de valores True ou False: True quando o valor está ausente e False quando está preenchido. Ao acrescentarmos sum(), o Pandas contabiliza esses valores e mostra quantos valores ausentes existem em cada coluna. Assim, podemos identificar rapidamente quais atributos precisam de atenção antes de realizar as análises.

print(sim_2022.isnull().sum())

Por exemplo, o resultado poderia ser:

idade             15
sexo               3
município          0
causa básica       0

Isso significa que existem 15 valores ausentes na coluna idade, 3 na coluna sexo e nenhum valor ausente nas demais colunas apresentadas.

Conversão do tipo de dado

O método astype(int) converte os valores da coluna idade para o tipo inteiro (int). Essa conversão pode ser necessária quando uma variável que deveria representar números foi carregada como outro tipo de dado, como texto ou número decimal. Ao atribuir o resultado novamente a sim_2022["idade_obito"], substituímos a coluna original pela versão convertida.

sim_2022["idade_obito"] = sim_2022["idade_obito"].astype(int)

É importante observar que essa conversão só funciona se os valores puderem ser convertidos para inteiros. Se a coluna contiver valores ausentes ou textos que não representam números, o comando poderá gerar um erro. Portanto, a verificação e o tratamento dos dados devem preceder a conversão. Se os dados puderem ser excluídos, o código a seguir pode ser uma opção.

# Identificar valores ausentes
print("Nulos encontrados na coluna idade_obito:", sim_2022.isnull().sum())

# Remover registros sem idade
sim_2022 = sim_2022.dropna(subset=["idade_obito"])

# Converter idade para inteiro
sim_2022["idade_obito"] = sim_2022["idade_obito"].astype(int)

Renomear coluna

O método rename() permite alterar os nomes das colunas de um DataFrame. Nesse caso, estamos substituindo o nome causabas_capitulo por cid_causabas_capitulo. O argumento columns recebe um dicionário no formato "nome_atual": "novo_nome", indicando quais nomes devem ser modificados. Como o rename() retorna um novo DataFrame, atribuímos o resultado novamente a sim_2022 para que a alteração seja efetivamente incorporada ao DataFrame.

sim_2022 = sim_2022.rename(
    columns={"causabas_capitulo": "cid_causabas_capitulo"}
)

Exclusão de linhas com drop()

O método drop() permite remover linhas específicas de um DataFrame, enquanto dropna() é utilizado para remover linhas que contêm valores ausentes (NaN). Por padrão, dropna() exclui qualquer linha que tenha pelo menos um valor ausente. Também é possível indicar uma ou mais colunas específicas, fazendo com que apenas os registros que apresentam valores ausentes nessas colunas sejam removidos.

# Excluir uma linha pelo índice
sim_2022 = sim_2022.drop(10)

# Excluir várias linhas pelos índices
sim_2022 = sim_2022.drop([10, 25, 40])

# Excluir linhas que possuem pelo menos um valor ausente
sim_2022 = sim_2022.dropna()

# Excluir linhas com idade ausente
sim_2022 = sim_2022.dropna(subset=["idade_obito"])

# Excluir linhas com município ou idade ausentes
sim_2022 = sim_2022.dropna(subset=["codigo_municipio", "idade_obito"])

No último exemplo, uma linha será excluída se apresentar valor ausente em codigo_municipio ou idade. O argumento subset permite, portanto, definir quais colunas devem ser consideradas na verificação dos valores ausentes. Essa opção é particularmente útil quando determinadas variáveis são essenciais para a análise.

Atenção

A exclusão de registros com valores ausentes deve ser feita com cuidado. Em bases de saúde pública, a ausência de dados pode ter significado e a remoção indiscriminada de registros pode reduzir a base ou introduzir viés na análise. Antes de utilizar dropna(), é importante verificar quantos registros serão eliminados e avaliar se essa decisão é adequada ao objetivo da análise.

Para Refletir
