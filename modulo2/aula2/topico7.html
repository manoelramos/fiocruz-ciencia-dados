Diagnóstico e inspeção inicial da base

Um erro comum entre analistas iniciantes é começar a realizar cálculos e obter médias logo após carregar uma base de dados. Em dados de saúde pública, é fundamental realizar primeiro uma inspeção inicial da base, verificando sua estrutura, seu conteúdo e a integridade dos dados. O Pandas oferece diversos métodos que facilitam essa etapa de análise exploratória.

No quadro a seguir, sim_2022 representa um DataFrame e são apresentados alguns dos principais métodos para realizar uma inspeção inicial dos dados:

Campos categóricos: unique() e value_counts()

Para variáveis qualitativas como: sexo, raça/cor, município ou causas CID, precisamos entender a variabilidade dos registros. As funções .unique() e .value_counts() são as ferramentas certas para esse diagnóstico:

# Lista as categorias distintas presentes no campo 'sexo'
print(sim_2022["sexo"].unique())

# Exibe a contagem absoluta de óbitos por causa básica, em ordem decrescente
print(sim_2022["causabas_capitulo"].value_counts())

Se a execução de unique() no campo sexo retornar ['F', 'M', 'FEMININO', 'masc', None], é uma evidência sobre falhas de padronização na digitação do sistema.

Você aprenderá como resolver essa questão no tópico sobre o tema limpeza.

Seleção de atributos e filtragem condicional

O Pandas permite tanto selecionar atributos (colunas) de um DataFrame quanto filtrar registros (linhas) de acordo com determinadas condições. Embora essas operações possam ser combinadas, é importante compreender cada uma separadamente.

Seleção de atributos

A seleção de atributos permite escolher quais colunas do DataFrame serão utilizadas na análise. Quando uma única coluna é selecionada diretamente, como sim_2022["idade_obito"], o resultado é uma Series. Quando uma lista de colunas é utilizada, mesmo que contenha apenas uma coluna, o resultado é um DataFrame. Por exemplo:

# Seleção de uma coluna → retorna uma Series
# sim2022 é um DataFrame
idades = sim_2022["idade_obito"]

# Seleção de uma coluna → retorna um DataFrame
idades = sim_2022[["idade_obito"]]

# Seleção de múltiplas colunas → retorna um DataFrame
subconjunto = sim_2022[["codigo_municipio", "idade_obito", "sexo"]]

Filtragem condicional

A filtragem condicional permite selecionar apenas os registros que atendem a uma ou mais condições. Por exemplo, podemos selecionar os óbitos de pessoas com 60 anos ou mais ou, combinando duas condições, selecionar apenas as pessoas do sexo feminino com 60 anos ou mais:

# Filtro simples: pessoas com 60 anos ou mais
idosos = sim_2022[sim_2022["idade_obito"] >= 60]

# Filtro composto: pessoas do sexo feminino com 60 anos ou mais
idosas = sim_2022[
    (sim_2022["idade_obito"] >= 60) & (sim_2022["sexo"] == "F")
]

Ao combinar duas ou mais condições no Pandas, não utilizamos os operadores and e or do Python. Para representar E lógico, usamos &; para OU lógico, usamos |. Cada condição deve ser colocada entre parênteses, como em df[(condicao1) & (condicao2)]. Essa sintaxe é necessária para que o Pandas avalie corretamente as condições.

Veja alguns exemplos:

# Pessoas com menos de 18 anos OU 60 anos ou mais
sim_2022[(sim_2022["idade_obito"] < 18) | (sim_2022["idade_obito"] >= 60)]

# Mulheres com 60 anos ou mais que residem no município de Itamonte
sim_2022[
    (sim_2022["idade_obito"] >= 60) &
    (sim_2022["sexo"] == "F") &
    (sim_2022["nome_municipio"] == "Itamonte")
]
